## 1. 系統目標與邊界

### 1.1 核心目標 (Goals)
1. **排程自動執行**：系統在每日台股與美股盤後自動執行。
2. **客觀量化評分**：系統計算 0 到 100 分量化分數。
3. **風報比嚴格把關**：推薦標的風報比 (RRR) 必須大於或等於 2.0。
4. **AI 風控審查**：系統使用 Gemini API 審查財務風險。系統剔除高風險標的。
5. **雙管道推播**：每日 08:00 前推播 Telegram 訊息。系統同步更新 GitHub Pages 頁面。
6. **零維護成本**：系統完全使用 GitHub Actions 免費額度。單次執行時間小於 4 分鐘。

### 1.2 非目標 (Non-Goals - 明確排除)
1. **不提供自動下單**：系統不串接券商 API。系統不代客下單。
2. **不做日內盤中監控**：系統不處理即時高頻交易資料。
3. **不維護虛擬持倉狀態**：系統每日產出最新獨立評分。系統不儲存歷史持倉狀態機。
4. **不使用付費數據 API**：系統不串接付費期權資料。財報預警採用公開交易日計算。

## 2. 使用者情境 (User Stories)

* **情境 1 (波段投資者)**：波段投資者希望在開盤前取得前 20 名標的。每檔標的具備進場價、停損價與目標價。
* **情境 2 (風險厭惡者)**：交易者希望每檔標的風報比大於等於 2.0。系統已自動排除財務異常股票。
* **情境 3 (系統維護者)**：維護者希望程式完全在 GitHub 免費額度內運作。程式不需自建伺服器。

## 3. 功能需求規格 (Functional Requirements)

### 3.1 資料獲取與還原 (FR-1)
- **台股母池篩選 (FR-1.1)**：涵蓋臺灣 50 與中型 100 指數成分股。收盤價大於 10 元。20 日平均成交額大於 5000 萬元新台幣。
- **美股母池篩選 (FR-1.2)**：涵蓋標普 500 與那斯達克 100 指數成分股。收盤價大於 5 美元。20 日平均成交額大於 1500 萬美元。
- **除權息還原 (FR-1.3)**：下載日 K 線資料時，參數設定 `auto_adjust=True`。避免均線產生人為跳空裂口。
- **休市日判定 (FR-1.4)**：系統檢查最新交易日。若當日無新資料，系統回傳退出碼 0 並終止程序。

### 3.2 大盤趨勢判斷 (FR-2)
- 系統計算加權指數 (^TWII) 與標普 500 指數 (^GSPC) 現價。
- 系統計算大盤 60 日均線 (MA60)。
- 若現價低於 MA60，系統設定市場狀態為「空頭防守」。推播與網頁強制置頂警示。

### 3.3 量化評分與風報比計算 (FR-3)
- **多因子評分 (FR-3.1)**：
  - 價值因子佔 30%：計算本益比、股價淨值比、自由現金流收益率。
  - 品質因子佔 25%：計算股東權益報酬率 (ROE)、毛利率穩定度。
  - 動能因子佔 20%：驗證均線多頭排列。計算 14 日 RSI 強度。
  - 市場特徵佔 25%：計算近期營收年增率。計算相對大盤強度。
  - 系統加權輸出 0 至 100 分總分。
- **風報比點位計算 (FR-3.2)**：
  - 停損價 = 現價 - (2 × ATR(14))。
  - 目標價 = 現價 + (2 × (現價 - 停損價))。
  - 風報比 (RRR) 固定設定為 2.0。
  - 系統依據 1% 本金風險，計算建議買進股數。

### 3.4 AI 機構風控審查 (FR-4)
- **金鑰輪詢機制 (FR-4.1)**：系統讀取 `GEMINI_API_KEYS` 環境變數。系統使用輪詢方式呼叫 API。若遭遇 429 限流錯誤，立即切換下一組金鑰。
- **重大風險否決 (FR-4.2)**：模型審查候選標的財務資料。若發現財務造假或重大利空，立即剔除該標的並遞補。
- **財報跳空預警 (FR-4.3)**：若標的在 5 個交易日內公布財報，系統標註「財報前夕」警示。

### 3.5 雙管道訊息發布 (FR-5)
- **Telegram 推播 (FR-5.1)**：系統發布 Markdown 格式訊息。訊息長度小於 3500 字元。內容包含：大盤警示、前 20 名清單、前 3 名機構點評、儀表板網址。
- **靜態網頁更新 (FR-5.2)**：系統產生 `docs/data/latest_tw.json` 與 `latest_us.json`。系統更新 `docs/index.html` 深色儀表板。

## 4. 驗收標準 (Acceptance Criteria)

- [ ] **驗收項 1 (資料還原)**：所有歷史股價均包含除權息還原。均線無除息裂口。
- [ ] **驗收項 2 (休市處理)**：休市日執行程式時，系統記錄「本日休市，跳過執行」。程式正常結束且不發送推播。
- [ ] **驗收項 3 (風報比達標)**：最終產出之 20 檔標的，風報比全部大於或等於 2.0。每檔標的具備停損價與目標價。
- [ ] **驗收項 4 (金鑰輪詢容錯)**：配置 2 組以上金鑰。第一組金鑰模擬 429 錯誤時，系統自動切換第二組金鑰完成作業。
- [ ] **驗收項 5 (推播長度合格)**：Telegram 推播字串長度小於 4000 字元。排版無異常斷行。
- [ ] **驗收項 6 (執行時間約束)**：單次工作流執行時間小於 4 分鐘。Commit 訊息包含 `[skip ci]` 標籤。

## 5. 系統模組架構表

| 模組路徑 | 模組職責 |
| :--- | :--- |
| `src/config.py` | 讀取環境變數。設定股票母池清單。管理 API 金鑰集。 |
| `src/data_fetcher.py` | 批次下載股價資料。判斷市場休市狀態。計算大盤季線。 |
| `src/quant_engine.py` | 計算多因子評分。計算 2 倍 ATR 停損目標點位。 |
| `src/ai_auditor.py` | 呼叫 Gemini 模型審查標的。標註財報公布倒數。 |
| `src/telegram_notifier.py` | 組合推播訊息。呼叫 Telegram API 發布晨報。 |
| `src/dashboard_builder.py` | 輸出資料檔案至 `docs/data/`。更新前端展示資料。 |
| `main.py` | 程式統一命令列入口。接收 `--market TW` 與 `--market US` 參數。 |
| `.github/workflows/` | 設定定時排程。執行自動化建置工作流。 |
