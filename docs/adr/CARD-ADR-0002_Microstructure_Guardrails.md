# 2. 微觀結構除權息還原與極簡風控防禦準則

Date: 2026-10-20

## Status
Accepted

## 對應規格書 (Specification)
- [CARD-SPEC-0001](../spec/CARD-SPEC-0001_每日機構級AI股票量化系統規格書.md) (章節 FR-1.3, FR-1.4, FR-2, FR-3.2)

## Context (背景與問題)
在真實市場交易中，常因「未做除權息復權還原」、「整張顆粒度與1%倉位衝突」、「大盤空頭盲目開倉」以及「排程在休市日重複運算」造成實戰嚴重虧損或系統資源浪費。

## Decision (決策與極簡解法)
1. 嚴格啟用 uto_adjust=True 獲取還原收盤價計算均線與風報比，杜絕除權息假斷崖。
2. 停損價與目標價一律採用客觀波動率公式：停損價 = 現價 - 2*ATR，目標價 = 現價 + 4*ATR (恆定 RRR = 2.0)。
3. 台股買進張數採向下取整 (loor)，資金不足買 1 張時標記為零股，絕不向上超額冒險。
4. 引入大盤 MA60 宏觀溫度計，大盤破季線強制亮出空頭防守警告。
5. 實作休市日自動阻斷，最新交易日相同時直接 sys.exit(0) 退出。

## Consequences (影響與收益)
- 以最少代碼成本 (KISS) 消除實戰重大風險。
- 零過度工程化，保持系統無狀態與高可靠性。
