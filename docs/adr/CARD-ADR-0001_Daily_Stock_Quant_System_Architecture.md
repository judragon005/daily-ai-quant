# 🏛️ [CARD-ADR-0001] 每日機構級 AI 股票量化系統：架構決策與推演歷程全紀錄

- **卡片編號**: CARD-ADR-0001

- **決策日期**: 2026-10-20

## 🎯 決策目標 (Goal)
建置一套每日股市收盤後自動更新、隔晨 08:00 前產出 20 檔可投資標的（評分 0-100、風報比 RRR $\ge 2.0$、興登堡做空一票否決）的雙市場量化研報系統。全系統要求 100% 免費、避免 GitHub Actions 封號，且堅守 KISS 原則拒絕過度工程化。

---

## 🔄 決策推演歷程全紀錄 (Decision Trail & Discussion Milestones)

本架構並非憑空產生，而是在單一會話內透過多輪高強度審查 (/grill-me 與 /grill-with-docs) 連續推演、直面漏洞並斧正收斂出的最終結果：

### 決策點 1：執行環境決策 (13:56)
- **問題**：系統該運行在本機 Windows 工作排程器、本機 Web Daemon，還是雲端排程？
- **論證**：本機排程需電腦 24 小時不關機或定時喚醒，穩定性易受休眠與本機網路影響。
- **決斷**：**採用 GitHub Actions 雲端定時排程**。完全免開電腦，且 100% 免費。

### 決策點 2：股票母池與初篩護城河決策 (13:58)
- **問題**：全市場美股 6,000+ 檔、台股 2,000+ 檔若無差別暴力掃描，會耗盡 CI 分鐘數並觸發 API 限流。
- **論證**：機構投資首重流動性防護，仙股即便分數高也是流動性陷阱。
- **決斷**：**採用方案 A「分層指數 + 流動性標準」**。美股以 S&P500 + Nasdaq100 為骨幹（約 550 檔）；台股以臺灣 50 + 中型 100 為基礎，擴充至均成交額 > 5,000 萬活躍股（約 350 檔）。批次拉取控制在 60 秒內。

### 決策點 3：雙軌評審與綜合仲裁決策 (14:00)
- **問題**：純量化與 AI 大模型該如何協同？
- **論證**：純量化計算快且客觀，但無法防範財報質押與商業假象；純 AI 耗費 Token 且有幻覺。
- **決斷**：**雙軌交叉仲裁 (Ensemble)**。
  - 軌道一：文藝復興多因子 (0-100分) + 大摩 2 倍 ATR 風報比 (RRR $\ge 2.0$)。
  - 軌道二：Gemini 機構面審查 (高盛存貨/FCF + 城堡資金流向)。
  - 終審死刑閘門：**興登堡做空一票否決**，凡觸發造假或重大地雷直接剔除。

### 決策點 4：交付管道與呈現形式決策 (14:01)
- **決斷**：**雙通道交付**。GitHub Pages 自動部署現代響應式儀表板（桌機/手機隨時瀏覽） + Telegram Bot 每日早晨 07:30~08:00 自動推播晨報摘要卡。

### 決策點 5：AI API Key 池抗封鎖架構 (14:02)
- **問題**：Gemini 免費 API 限制為 15 RPM，單一 Key 在批次審查時易遭限流報錯。
- **決斷**：**建立 Gemini API Key 池 (Key Rotation)**。自環境變數讀取多個免費帳號之 Key，輪詢切換與自動容錯重試，達成 100% 免費高可用。

### 決策點 6：GitHub Actions 服務條款與防封號深度防禦 (14:05)
- **問題**：如何徹底避免因使用定時排程、抓取數據而遭 GitHub 停權封號？
- **深度調研與決斷**：
  1. 嚴禁使用 on: push 觸發，僅允許 schedule 與 workflow_dispatch，Git commit 一律附帶 [skip ci]，徹底斬斷無限遞迴迴圈。
  2. 錯峰排程避開全球整點塞車：台股設定為 16:17 執行，美股設定為 05:23 執行。
  3. 單次執行時間嚴格控制在 3~4 分鐘內，每月僅消耗約 240 分鐘（佔免費額度 12%）。
  4. 專案採用私有倉庫，Secrets 絕對不硬編碼外洩。

### 決策點 7：專案物理隔離與 Matt Pocock 技能庫引進 (14:24)
- **問題**：如何避免影響「諮詢」目錄下的其他業務？
- **決斷**：**建立頂層獨立專案 D:\APP\每日機構級AI股票量化系統**，專屬獨立 Git 倉庫，並將 Matt Pocock 最新 38 個繁中技能庫完全收攏於該專案內，母目錄零污染。

### 決策點 8：拒絕過度工程化——3 大極簡防護補強 (14:34)
- **反省與裁撤**：堅決砍掉「虛擬持倉狀態機」、「處置股爬蟲」與「期權隱含波動鏈抓取」，以奧坎剃刀原則收斂為 4 項極簡代碼槓桿：
  1. **除權息還原**：yfinance 開啟 uto_adjust=True（1 行代碼），杜絕假跳空。
  2. **休市日阻斷**：最新交易日相同時直接 sys.exit(0) 退出，避免推播重複垃圾與浪費分鐘數。
  3. **大盤季線防空警報**：大盤 < MA60 時頂部亮紅燈，防範熊市盲目做多。
  4. **Telegram 防爆門**：摘要卡控制在 3500 字元以內，附帶網頁連結，確保 100% 成功發送。
